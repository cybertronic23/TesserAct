# TesserAct 项目代码分析文档

> TesserAct: Learning 4D Embodied World Models - ICCV 2025

## 1. 项目概述

**TesserAct** 是一个 4D 世界模型，能够根据输入图像和文本指令生成 RGB、Depth、Normal 视频，重建 4D 场景并预测机器人动作。项目基于 CogVideoX-5B-I2V 构建，扩展支持多模态视频生成。

### 1.1 核心特性

- **多模态输出**: 同时生成 RGB + Depth + Normal 视频
- **动作预测**: 输入文本指令，生成相应的机器人动作视频
- **4D 重建**: 结合深度图和法向量图进行场景重建
- **高效微调**: 支持 LoRA 高效微调

## 4. 主要代码逻辑主线

### 4.1 训练流程

```
数据准备 → 模型加载 → VAE编码 → 噪声添加 → Transformer前向 → 损失计算 → 反向传播
```

**核心流程 (`i2v_depth_normal_sft.py`)**:

```
main()
├── 1. 初始化 Accelerator (分布式训练)
├── 2. 加载模型组件
│   ├── tokenizer (T5)
│   ├── text_encoder (T5EncoderModel)
│   ├── transformer (TesserActDepthNormal)
│   ├── vae (AutoencoderKLCogVideoX)
│   └── scheduler (CogVideoXDPMScheduler)
├── 3. 配置优化器 (AdamW)
├── 4. 创建 DataLoader + BucketSampler
├── 5. 训练循环
│   ├── for step, batch in enumerate(train_dataloader):
│   │   ├── images = batch["images"].to(device)      # 首帧 [B, C, H, W]
│   │   ├── videos = batch["videos"].to(device)      # 目标视频 [B, T, C, H, W]
│   │   ├── VAE 编码: image_latents, video_latents
│   │   ├── 添加图像噪声: noisy_images
│   │   ├── 文本编码: prompt_embeds
│   │   ├── 采样 timestep
│   │   ├── 计算 RoPE 位置编码
│   │   ├── Transformer 前向: model_output
│   │   ├── 计算速度: model_pred
│   │   ├── 计算 RGB + Depth + Normal 分项损失
│   │   ├── loss = rgb_loss + depth_loss + normal_loss
│   │   ├── accelerator.backward(loss)
│   │   ├── 梯度裁剪 + 优化器更新
│   │   └── 学习率调度
│   ├── checkpoint 保存
│   └── validation 验证
└── 6. 模型保存
```

### 4.2 推理流程

```
输入图像 → 深度/法向量估计 → Pipeline 推理 → 去噪循环 → VAE 解码 → 输出视频
```

**核心流程 (`inference_rgbdn_sft.py`)**:

```

├── 2. 加载自定义 Transformer 权重

│   ├── 加载并预处理 Depth 图
│   ├── 加载并预处理 Normal 图
│   ├── 拼接: [RGB(3), Depth(3), Normal(3)] → 9通道
│   └── pipe(
│       image=image_9ch,        # 条件图像
│       prompt=text,           # 文本指令

│       num_inference_steps=50

│   └── output: [T, H, W, 9] 的视频帧
└── 4. export_to_video() 保存结果
```

## 5. 关键核心代码结构解读

### 5.1 TesserActDepthNormal 模型 (`tesseract_model.py`)

继承自 `CogVideoXTransformer3DModel`，是核心的 Transformer 模型：

```python
class TesserActDepthNormal(TesserActDepth):
    def __init__(self, ...):
        # 1. 重新定义 Patch Embedding
        self.patch_embed = TesserActDepthNormalPatchEmbed(...)

        # 2. Depth+Normal 输出投影
        self.dn_out_proj = Conv3DNet(...)  # 3D卷积网络
        self.dn_out = MLP(...)             # 多层感知机

    def forward(self, hidden_states, ...):
        # 1. Time embedding
        t_emb = self.time_embedding(self.time_proj(timesteps))

        # 2. Patch embedding (处理 RGB + Depth + Normal)
        depth_input_state = hidden_states[:, :, channels//3 : channels//3*2]
        normal_input_state = hidden_states[:, :, channels//3*2 :]
        hidden_states = self.patch_embed(encoder_hidden_states, hidden_states)

        # 3. Transformer blocks
        for block in self.transformer_blocks:
            hidden_states, encoder_hidden_states = block(...)

        # 4. RGB 输出
        rgb_output = self.proj_out(hidden_states)

        # 5. Depth + Normal 输出
        rdn_input_state = torch.cat([rgb_output, depth_input_state, normal_input_state], dim=2)
        rdn_input_state = self.dn_out_proj(rdn_input_state)
        depth_states = self.dn_out(torch.cat([hidden_states, rdn_input_state], dim=-1))

        # 6. 拼接输出
        output = torch.cat([rgb_output, depth_states], dim=2)
        return output
```

**关键设计**:
- 使用 `TesserActDepthNormalPatchEmbed` 分离处理 RGB、Depth、Normal 三个通道
- 使用 `Conv3DNet` 和 `MLP` 生成 Depth 和 Normal 的残差
- 最终输出通道数 = 原始 16 × 2 (RGB 8ch + DN 8ch)

### 5.2 TesserActDepthNormalPatchEmbed (`embeddings.py`)

自定义的 Patch Embedding 层，分离处理三种模态：

```python
class TesserActDepthNormalPatchEmbed(TesserActDepthPatchEmbed):
    def __init__(self, **kwargs):
        super().__init__(**kwargs)
        # 新增 Normal 投影层
        self.normal_proj = nn.Conv2d(in_channels, embed_dim, ...)

    def forward(self, text_embeds, image_embeds):
        # 分离 RGB, Depth, Normal
        rgb_embeds = image_embeds[:, : channels // 3]
        depth_embeds = image_embeds[:, channels//3 : channels//3*2]
        normal_embeds = image_embeds[:, channels//3*2 :]

        # 分别投影并相加
        image_embeds = self.proj(rgb_embeds)     # RGB 投影
        image_embeds += self.depth_proj(depth_embeds)   # Depth 残差
        image_embeds += self.normal_proj(normal_embeds)  # Normal 残差

        return torch.cat([text_embeds, image_embeds], dim=1)
```

### 5.3 TesserActImageToDepthNormalVideoPipeline (`tesseract_pipeline.py`)

扩展自 CogVideoX 的推理 Pipeline，处理多模态条件：

```python
class TesserActImageToDepthNormalVideoPipeline(CogVideoXImageToVideoPipeline):
    def prepare_latents(self, image, ...):
        # image: [B, C=9, H, W] (RGB:3 + Depth:3 + Normal:3)
        # 分割为三个 3 通道
        image = image.reshape(B * 3, C // 3, H, W)
        image_latents = [vae.encode(img) for img in image]
        image_latents = torch.cat(image_latents, dim=0)  # [B, C*3, F, H, W]

    def __call__(self, image, prompt, ...):
        # 1. 编码 prompt
        prompt_embeds = self.encode_prompt(prompt, ...)

        # 2. 准备 latents (图像 latent + 视频噪声 latent)
        latents, image_latents = self.prepare_latents(image, ...)

        # 3. 去噪循环
        for i, t in enumerate(timesteps):
            # 分离 RGB/Depth/Normal latent
            latent_image_rgb = image_latents[:, :, :C//3]
            latent_image_depth = image_latents[:, :, C//3:C*2//3]
            latent_image_normal = image_latents[:, :, C*2//3:]

            # 拼接为 6 倍通道输入
            latent_model_input = torch.cat([
                video_latent_rgb, image_latent_rgb,
                video_latent_depth, image_latent_depth,
                video_latent_normal, image_latent_normal
            ], dim=2)

            # Transformer 预测噪声
            noise_pred = self.transformer(latent_model_input, ...)

            # 调度器步进
            latents = self.scheduler.step(noise_pred, ...)

        # 4. VAE 解码
        video = self.decode_latents(latents)
        return video
```

### 5.4 RoboDepthNormal 数据集 (`robodataset.py`)

数据集类，支持加载 RGB + Depth + Normal 三元组：

```python
class RoboDepthNormal(RoboDepth):
    def _preprocess_video(self, path):
        # 1. 加载 RGB 视频
        rgb_video = self._read_rgb_data(rgb_dir)  # [T, H, W, 3]

        # 2. 加载 Depth 数据
        depth_path = Path(str(rgb_dir).replace("video", "depth/npz").replace("rgb.mp4", "depth.npz"))
        depth_video = self._read_depth_data(depth_path)  # [T, H, W]

        # 3. 加载 Normal 数据
        normal_path = Path(str(rgb_dir).replace("rgb", "video/normal.mp4"))
        normal_video = self._read_rgb_data(normal_path)  # [T, H, W, 3]

        # 4. 拼接并转换
        concatenated_video = torch.cat([rgb_video, depth_video, normal_video], dim=1)
        # concatenated_video: [T, 9, H, W]

        return image, concatenated_video, mask  # mask 标记有效模态

    def getitem(self, index):
        return {
            "prompt": "...",  # 文本指令
            "image": image,   # 首帧 [1, 9, H, W]
            "video": video,   # 目标视频 [T, 9, H, W]
            "mask": [rgb_mask, depth_mask, normal_mask],  # 有效模态掩码
        }
```

## 6. 运行脚本解析

### 6.1 SFT 全量微调训练

**脚本**: `train_i2v_depth_normal_sft.sh`

```bash
#!/bin/bash
# 主要配置
MODEL_PATH="THUDM/CogVideoX-5b-I2V"
OUTPUT_DIR="./output/tesseract_rgbdn_sft"

# 数据配置
frame_length=49
height=480
width=640
train_batch_size=1
max_train_steps=40000

# 训练命令
deepspeed tesseract/i2v_depth_normal_sft.py \
    --pretrained_model_name_or_path=$MODEL_PATH \
    --output_dir=$OUTPUT_DIR \
    --max_num_frames=$frame_length \
    --height=$height \
    --width=$width \
    --train_batch_size=$train_batch_size \
    --num_train_epochs=1000 \
    --max_train_steps=$max_train_steps \
    --gradient_accumulation_steps=1 \
    --learning_rate=5e-5 \
    --validation_prompt="..." \
    --validation_images="..." \
    --save_strategy=steps \
    --checkpointing_steps=1000 \
    --gradient_checkpointing \
    --mixed_precision=bf16
```

## 10. 核心代码流程图

```
┌─────────────────────────────────────────────────────────────────┐
│                        输入处理                                  │
├─────────────────────────────────────────────────────────────────┤
│  RGB 图像 (3ch) ──┐                                              │
│  Depth 图 (3ch) ──┼──→ 拼接 → [9, H, W] ──→ VAE 编码 ──→ Image Latents
│  Normal 图 (3ch) ─┘                                              │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                     Transformer 前向                             │
├─────────────────────────────────────────────────────────────────┤
│  Video Latents (9ch) ─┐                                         │
│  Image Latents (9ch) ─┼──→ 拼接 [18ch] ──→ Transformer ──→ Noise Pred
│  Text Embeddings ─────┘                                         │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                        损失计算                                  │
├─────────────────────────────────────────────────────────────────┤
│  Noise Pred → RGB Pred + Depth Pred + Normal Pred                │
│  Target = Video Latents                                          │
│  Loss = MSE(RGB_pred, RGB_target)                                │
│       + MSE(Depth_pred, Depth_target)                            │
│       + MSE(Normal_pred, Normal_target)                          │
└─────────────────────────────────────────────────────────────────┘
```

## 11. 技术栈总结
